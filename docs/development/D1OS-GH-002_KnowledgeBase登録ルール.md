# D1OS-GH-002

# Knowledge Base登録ルール

Version: 1.0

---

# 目的

本ルールは、D1OS開発で得られた知識をGitHubへ体系的に保存し、AIと人が共通の知識を利用できるようにするための基準である。

---

# 保存する情報

次の情報はKnowledge Baseへ保存する。

・開発手順
・環境構築方法
・設計思想
・運用ルール
・検証結果
・エラーと解決方法
・再利用できるテンプレート
・長期的に利用するノウハウ

---

# 保存しない情報

次の情報はKnowledge Baseへ保存しない。

・一時的なメモ
・雑談
・途中の思考整理
・未検証の推測
・その場限りの作業ログ

---

# 保存場所

docs/

　development/
　　開発手順・運用ルール

migration/
　　引っ越し構文
　　Runtime Export

README.md
　　入口説明

---

# 登録判断

迷った場合は次の基準で判断する。

一度だけ使う情報

↓

保存しない

複数回使う情報

↓

Knowledge Baseへ保存する

---

# 基本原則

同じ内容を複数の文書へ重複登録しない。

既存文書へ追記できる場合は、新しい文書を増やさない。

Knowledge Baseは検索しやすさと保守性を最優先とする。
