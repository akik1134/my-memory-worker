Version: 1.0

Purpose:

# 11. PC変更時の復元手順

新PCでは、以下の順番で復元します。

## 11.1 事前準備

- GitHubアカウントでログインできること
- Cloudflareアカウントでログインできること
- VS Code と PowerShell を利用できること

## 11.2 復元手順

1. GitHubからリポジトリをcloneする
2. プロジェクトフォルダへ移動する
3. 依存関係をインストールする
4. Cloudflare にログインする
5. D1 マイグレーションを適用する
6. 開発サーバーまたはデプロイを実行する
7. 動作確認を行う

```powershell
cd Documents
git clone https://github.com/akik1134/my-memory-worker.git
cd my-memory-worker
npm install
npx wrangler d1 migrations apply DB --local
npx wrangler dev
```

## 11.3 復元後の確認項目

- GitHub から取得できている
- npm install が成功している
- Wrangler が利用できる
- Cloudflare 認証が完了している
- Worker が応答する
- D1 接続が正常である
